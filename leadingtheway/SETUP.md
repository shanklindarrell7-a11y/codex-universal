# Setup Instructions

## Prerequisites

- Node.js (version 18 or higher)
- Git

## Installation

1. Navigate to the project directory:
   ```bash
   cd leadingtheway
   ```

2. Install dependencies (if any):
   ```bash
   npm install
   ```

## Running the Application

To start the application:
```bash
npm start
```

## Testing

To run tests:
```bash
npm test
```
